CERN CMS Dimuon Data Analysis & Machine Learning

Project Overview

This project explores CERN CMS dimuon collision data using Python, statistical analysis, data visualization, and machine learning.

The main objective is to analyze particle collision events, study the Z boson mass distribution, and identify unusual collision events using an unsupervised machine learning algorithm.

Dataset

- Dataset: Dimuon DoubleMu CSV
- Total events: 100,000
- Data source: CERN CMS experimental dataset

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Machine Learning (Isolation Forest)

Analysis Performed

1. Data inspection and quality analysis.
2. Missing-value and duplicate-record detection.
3. Dimuon invariant mass calculation and visualization.
4. Z boson mass analysis.
5. Statistical accuracy evaluation.
6. Machine learning anomaly detection.
7. Extraction and analysis of anomalous events.

Key Results

- Total events analyzed: 100,000
- Normal events: 98,000
- Anomalous events: 2,000
- Estimated Z boson mass: 91.23695 GeV
- Reference Z boson mass: 91.2 GeV
- Percentage error: approximately 0.04%

Machine Learning

The Isolation Forest algorithm was used to identify unusual patterns in particle collision data.

The model classified events into normal and anomalous categories.

Project Goal

To develop practical skills in scientific Python, particle physics data analysis, statistical interpretation, and machine learning, with applications to experimental physics research.
